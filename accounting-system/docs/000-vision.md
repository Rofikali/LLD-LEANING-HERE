# Vision

## Problem

Small and medium businesses need an accounting system capable of managing:

- Journal Entries
- Ledgers
- Trial Balance
- Profit & Loss
- Balance Sheet

## Goal

Build a production-grade accounting engine using:

- Python
- PostgreSQL
- Domain Driven Design
- Event Driven Architecture

## Success Criteria

System can:

- Record journal entries
- Generate trial balance
- Generate balance sheet
- Generate P&L
- Maintain audit history

## Non Goals

- Payroll
- GST Filing
- Banking Integration
- Inventory Management

## Constraints

- Double entry accounting
- Immutable journal entries
- Full auditability
